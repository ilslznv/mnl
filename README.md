# manool — первый экран

Запуск: `npm run dev`, затем http://localhost:3000. Установка зависимостей не нужна. Можно также открыть index.html напрямую.

Оригинальные SVG, изображение и локальный TT Travels. Адаптивная вёрстка, смена слов и цвета каждые 2 секунды, поддержка reduced motion, мобильное меню, просмотр проекта в диалоге. Контактные кнопки открывают почту.

На десктопе композиция рассчитывается по ширине и высоте окна (100svh): заголовок привязан к низу, карточка — к верху. Затемнение, название и ссылка карточки появляются при наведении или фокусе с клавиатуры. Переход слов использует перекрывающиеся волны букв без размытия и синхронную смену ширины и цвета плашки.

По явному запросу анимации включены для этой страницы атрибутом `data-motion="full"` на `<html>`, даже если ОС сообщает prefers-reduced-motion. Настройки ОС не меняются. Удаление атрибута возвращает автоматическое соблюдение этого предпочтения.

Полные разделы «Процесс», «Команда» и кейс в исходных материалах отсутствуют: пока используются небольшие диалоги. Точные адреса Instagram и Telegram не предоставлены, поэтому ig./tg. открывают контактный диалог. Перед публикацией замените их на реальные ссылки.


## Концепции

- `/` и `/1` — исходный белый экран.
- `/2` — тёмный плакат с лаймовым акцентом, крупной типографикой и вертикальной карточкой.
- `/3` — тёплая журнальная композиция с центральным заголовком и лавандовым знаком студии.

Страницы `concept-2.html` и `concept-3.html` используют общие `style.css`, `script.js` и дополнительные стили `concepts.css`. Все три адреса обслуживает `server.mjs`; для другого хостинга нужно настроить соответствующие маршруты. Логотип с тёмной надписью находится в `logofull-dark.svg`.
